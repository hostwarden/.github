# Getting help

- **A question, or an idea not ready for an issue:** ask in
  [Discussions](https://github.com/hostwarden/hostwarden/discussions)
  of the Hostwarden repository.
- **A bug or a concrete change:** open an issue in the repository it
  concerns. For Hostwarden, read its
  [CONTRIBUTING.md](https://github.com/hostwarden/hostwarden/blob/main/CONTRIBUTING.md)
  first; it asks you to search the existing issues before opening a
  new one.
- **A security problem:** report it privately, as the repository's
  SECURITY.md describes, never in public.
