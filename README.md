# hostwarden/.github

The organization profile and the default community health files of
Hostwarden.

- `profile/README.md` is what GitHub shows on
  https://github.com/hostwarden.
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`,
  `SUPPORT.md` and `.github/FUNDING.yml` apply to every repository
  of the organization that has no file of the same kind itself. A
  repository's own file always wins: Hostwarden's `CONTRIBUTING.md`,
  `SECURITY.md` and `FUNDING.yml` are its own.

There are deliberately no default issue or pull request templates
here: they would apply to Hostwarden too, whose pull requests follow
the rules in its own repository.
