# Contributing

Contributions to Hostwarden itself follow
[its CONTRIBUTING.md](https://github.com/hostwarden/hostwarden/blob/main/CONTRIBUTING.md).
This file covers the organization's other repositories.

- For anything beyond a small fix, open an issue first, so the
  approach is settled before the work is done.
- Commit messages and pull request titles follow
  [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/).
  Pull requests are squash-merged, so the title becomes the commit
  on `main`.
- Read the repository's `AGENTS.md` where it has one: it names the
  commands to run before pushing and what not to change by hand.
- Everyone who takes part agrees to the
  [Code of Conduct](CODE_OF_CONDUCT.md).
