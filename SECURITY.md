# Security policy

Report a vulnerability privately through GitHub: **Security →
Report a vulnerability** on the repository it concerns. Do not open
a public issue, discussion or pull request for it.

Hostwarden itself, `hostwarden/hostwarden`, has a policy of its own
with what counts and what does not:
[its SECURITY.md](https://github.com/hostwarden/hostwarden/blob/main/SECURITY.md).
This file covers the organization's other repositories.
